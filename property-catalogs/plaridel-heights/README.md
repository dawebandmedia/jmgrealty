# Plaridel Heights public catalog notes

Reviewed 17 October 2026. public-model-summary.json contains the seven model/design records used by the website, anonymous price/area examples and filter bounds. It contains no buyer records, block/lot identities or available-inventory list.

All price samples are undated. TCP figures precede conditional promotional deductions; reservation and loan examples are not treated as active terms. Modern Minimalist has no separately matched price or measured specification. Nero, Strata and Solenne share a series computation and shared Brisa presentation drawings, with matching limitations stated on their pages. Dogwood's 72 sqm sample needs an exact matching plan.

Original flyers exist only for Clara and Esia in the supplied archives. Other models have a flyer request instead of an invented original. Asset filenames and source hashes are recorded in app/plaridel-assets.json. The complete original flyer PDFs and clean static masterplan are in public/documents/plaridel-heights. Website images and optimized display copies are in public/images/properties/plaridel-heights. The 25 large master images are stored separately in the optional originals archive; their website links use the existing optimized images.

The community-level static masterplan credits UnionBank, Sta. Lucia and Royale Homes. The model flyers identify the 5R collection. The 87-hectare community description comes from the owner. Current contracting parties, package specifications, fees, inclusions, turnover and availability need confirmation.

# Confidentiality audit

This report names categories and neutral source IDs only. It reproduces no client records, private contact data, lot numbers, stock counts, internal incentives or negotiated prices.

## Excluded

- Inventory source: excluded from the output and website. Only metadata was checked.
- All 27 raw price/computation PDFs: excluded. Only a generic dated model-level package reference from the clearly labeled official price portion is used.
- Full seminar: excluded. Inventory-related site/availability context and individual pricing content are not reproduced. Selected generic model and marketing pages are rendered separately.
- Original HEIC GPS/EXIF metadata: excluded from published conversions. Original source files remain in the input folder.

## Requires Confidentiality Review

- Individual lot sample computations, any source inventory identifiers and non-public discounts or negotiations.
- Any source site plan that may encode inventory status.
- Exact nonstandard lot-size price variants whose supplied records identify individual inventory.

These items are excluded from the website-ready dataset until the developer provides a public model-level reference or publication approval. No sensitive details are included in this review list.

## Included

Named generic model plans, model-folder photographs, public promotional images, generic requirements/inclusions/map documents, anonymous model-level dated package prices, public project facts and source attribution. Model or room associations that lack source labels remain unverified and shared.
